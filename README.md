# Самопроверка экзаменационных материалов и УМКД

Открытый сайт самопроверки для профессорско-преподавательского состава КазНУ им. аль-Фараби.
Офис академической аналитики и контроля качества образования (ОААиККО).

- `tests/` — самопроверка тестовых заданий (чек-лист Ф 708-02-26).
- `written/` — самопроверка письменных и устных заданий (чек-лист Ф 708-02-26, 10 критериев).
- `umkd/` — самопроверка УМКД перед экспертизой (чек-лист экспертизы УМКД ОААиККО, критерии B1–B7, МУ от 06.01.2025).

Интерфейс на русском и казахском языках. Все файлы обрабатываются только в браузере пользователя и никуда не загружаются.
Результатов экспертизы, паролей и ключей в этом репозитории нет: они хранятся на портале ОААиККО.

Каждый раздел — один `index.html`, сборки нет. Меню сайта — в `nav.js`.
